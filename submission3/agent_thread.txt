================================================================================
Coding-agent thread — governed via the Unity Gateway (Section C + bonus)
================================================================================
Extends governance to agentic workflows: the coding agent's LLM traffic AND its
MCP calls are routed through a governed gateway. The agent has its OWN governed
endpoint (northpeak-agent-gateway) distinct from the app's, with its own inference
table (gw_agent / agent_inference_table.json).

--------------------------------------------------------------------------------
1) The call to ucode (coding agent), model routed through the governed endpoint
--------------------------------------------------------------------------------
# The coding agent's model calls are pointed at the governed Databricks endpoint,
# so every agent LLM invocation is bounded (rate limits + $0.05 budget), guarded
# (safety/PII + all-data guardrail), and traced (inference table).

$ export UCODE_MODEL_BASE_URL="https://fe-sandbox-rkm-sandbox-1.cloud.databricks.com/serving-endpoints"
$ export UCODE_MODEL_ENDPOINT="northpeak-agent-gateway"
$ export UCODE_GATEWAY_INFERENCE_TABLE="rkm_sandbox_1_catalog.demo_workshop_northpeak_retail_stockout_markdown_rescue.agent_inference_table"

$ ucode --model-endpoint "$UCODE_MODEL_ENDPOINT" \
        --model-base-url "$UCODE_MODEL_BASE_URL" \
        --mcp-config ./.mcp/agent_mcp.json \
        "Post the AI-spend governance report to my Slack."

[ucode] model provider = databricks (governed)
[ucode] endpoint       = northpeak-agent-gateway   (external-model gateway)
[ucode] every model call + MCP-triggered model call is logged to gw_agent
[ucode] loading MCP servers from ./.mcp/agent_mcp.json ...
